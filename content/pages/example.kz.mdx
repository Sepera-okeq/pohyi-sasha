## ✨ Мүмкіндіктер

Осы конфигурациямен сіз мыналарды жасай аласыз:
- ✅ MDX файлдарында тікелей **орындалатын TSX кодын** жазу
- ✅ React хуктарын пайдалану (useState, useEffect және т.б.)
- ✅ Локализация үшін Next-intl-ге қол жеткізу
- ✅ Tailwind CSS кластарын пайдалану
- ✅ Оқиға өңдеушілерімен интерактивті компоненттерді жасау
- ✅ Компоненттерге props беру

## 📝 Бұл қалай жұмыс істейді

1. `components/mdx/your-component.tsx` файлында компонент жасаңыз:

```tsx
'use client';

import { useState } from 'react';

export function YourComponent() {
  const [count, setCount] = useState(0);
  
  return (
    <div className="p-4 bg-blue-500 text-white rounded-lg">
      <button onClick={() => setCount(count + 1)}>
        {count} рет басылды
      </button>
    </div>
  );
}
```

2. Компонент автоматты түрде MDX-те қолжетімді - оны пайдаланыңыз:

```mdx
# Менің бетім

<YourComponent />
```

Импорттар қажет емес! Компоненттер MDX рендерерінде глобалды тіркелген.
