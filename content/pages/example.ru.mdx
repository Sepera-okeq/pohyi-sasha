## ✨ Возможности

С этой настройкой вы можете:
- ✅ Писать **исполняемый TSX код** прямо в MDX файлах
- ✅ Использовать React хуки (useState, useEffect и т.д.)
- ✅ Получать доступ к Next-intl для локализации
- ✅ Использовать классы Tailwind CSS
- ✅ Создавать интерактивные компоненты с обработчиками событий
- ✅ Передавать props в компоненты

## 📝 Как это работает

1. Создайте компонент в `components/mdx/your-component.tsx`:

```tsx
'use client';

import { useState } from 'react';

export function YourComponent() {
  const [count, setCount] = useState(0);
  
  return (
    <div className="p-4 bg-blue-500 text-white rounded-lg">
      <button onClick={() => setCount(count + 1)}>
        Нажато {count} раз
      </button>
    </div>
  );
}
```

2. Компонент автоматически доступен в MDX - просто используйте его:

```mdx
# Моя страница

<YourComponent />
```

Никаких импортов не нужно! Компоненты зарегистрированы глобально в рендерере MDX.
