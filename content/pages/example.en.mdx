This page demonstrates how to use MDX to write rich content with React components.

## Features

You can:
- Write **Markdown** content normally
- Use inline JSX/TSX components with `<div>`, `<span>`, etc.
- Style components with inline styles or className
- Import external React components from separate files

## Code Example

To use custom React components with hooks and localization, create a separate component file:

```tsx
// components/custom-box.tsx
'use client';

import { useTranslations } from 'next-intl';

export function CustomBox() {
  const t = useTranslations('features');
  return (
    <div className="p-8 bg-blue-600 text-white rounded-lg">
      <h2>{t('feature1.title')}</h2>
      <p>{t('feature1.description')}</p>
    </div>
  );
}
```

Then import it in your MDX:

```mdx
import { CustomBox } from '@/components/custom-box';

# My Page

<CustomBox />
```

This approach gives you full access to React hooks, localization, and all Next.js features!
