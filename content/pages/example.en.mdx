## 📝 How It Works

1. Create a component in `components/mdx/your-component.tsx`:

```tsx
'use client';

import { useState } from 'react';

export function YourComponent() {
  const [count, setCount] = useState(0);
  
  return (
    <div className="p-4 bg-blue-500 text-white rounded-lg">
      <button onClick={() => setCount(count + 1)}>
        Clicked {count} times
      </button>
    </div>
  );
}
```

2. The component is automatically available in MDX - just use it:

```mdx
# My Page

<YourComponent />
```

No imports needed! The components are registered globally in the MDX renderer.
