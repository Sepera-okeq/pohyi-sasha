## Features

- Styled with inline styles (works in MDX)
- Responsive design
- Dark mode compatible
- Can be used directly in MDX files
- Easily customizable

## Usage with shadcn/ui Components

To use shadcn/ui Table components, create a separate React component file:

```tsx
// components/data-table.tsx
'use client';

import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table"

export function DataTable() {
  return (
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead>ID</TableHead>
          <TableHead>Name</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow>
          <TableCell>#001</TableCell>
          <TableCell>Item 1</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  );
}
```

Then import and use it in your MDX:

```mdx
import { DataTable } from '@/components/data-table';

# My Page

<DataTable />
```

This approach gives you full access to all shadcn/ui components and TailwindCSS classes!
