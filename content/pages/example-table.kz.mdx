# MDX-тегі нақты shadcn/ui Table компоненті

Бұл бет MDX-ке тікелей біріктірілген **нақты, орындалатын shadcn/ui Table компонентін** көрсетеді!

## 📊 shadcn/ui көмегімен тірі деректер кестесі

Төменде стилденген күй белгілері және интерактивті hover эффектілері бар **нақты** shadcn/ui Table компоненті берілген:

<DataTableDemo />

## ✨ Сіз не көріп отырсыз

Бұл статикалық HTML немесе код мысалы емес - бұл мыналарды пайдаланатын **нақты React компоненті**:
- ✅ shadcn/ui Table компоненттері (TableHeader, TableRow, TableCell және т.б.)
- ✅ Стилизация үшін Tailwind CSS кластары
- ✅ JavaScript деректерінен динамикалық рендеринг
- ✅ Шартты стилизациясы бар күй белгілері
- ✅ Қараңғы режимді қолдау
- ✅ Респонсивті дизайн

## 🎯 Компонент коды

`DataTableDemo` компоненті `components/mdx/data-table-demo.tsx` файлында анықталған:

```tsx
'use client';

import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from '@/components/ui/table';

const invoices = [
  { id: 'INV001', status: 'Paid', method: 'Credit Card', amount: '$250.00' },
  { id: 'INV002', status: 'Pending', method: 'PayPal', amount: '$150.00' },
  // ... көбірек деректер
];

export function DataTableDemo() {
  return (
    <Table>
      <TableCaption>Сіздің соңғы шоттарыңыздың тізімі.</TableCaption>
      <TableHeader>
        <TableRow>
          <TableHead>Шот</TableHead>
          <TableHead>Күй</TableHead>
          <TableHead>Әдіс</TableHead>
          <TableHead className="text-right">Сома</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        {invoices.map((invoice) => (
          <TableRow key={invoice.id}>
            <TableCell>{invoice.id}</TableCell>
            <TableCell>{invoice.status}</TableCell>
            <TableCell>{invoice.method}</TableCell>
            <TableCell className="text-right">{invoice.amount}</TableCell>
          </TableRow>
        ))}
      </TableBody>
    </Table>
  );
}
```

## 🚀 Қалай пайдалану

MDX файлыңызда компонент атын пайдаланыңыз:

```mdx
# Шоттар бетім

<DataTableDemo />
```

Импорттар қажет емес! Компонент MDX рендерерінде глобалды тіркелген және пайдалануға дайын.

## 📈 Көбірек shadcn/ui компоненттері

Сіз кез келген shadcn/ui компонентін осылай пайдалана аласыз:
- Кестелер (жоғарыда көрсетілгендей)
- Графиктер (recharts көмегімен)
- Формалар, Диалогтар, Ашылмалы тізімдер
- Карточкалар, Белгілер, Батырмалар
- Және көптеген басқалары!

`components/mdx/` ішінде компонент жасап, оны page.tsx файлында тіркеңіз.
